# Koreksi LJK AI — Frontend

Sistem Koreksi LJK Otomatis berbasis web + AI (PG, isian singkat, uraian). Frontend statis (HTML/CSS/JS vanilla) untuk GitHub Pages; backend berupa Google Apps Script (JSON API).

- Kosongkan `GAS_URL` di `js/config.js` → **mode demo** (data contoh di peramban, AI simulasi).
- Isi `GAS_URL` dan `GOOGLE_CLIENT_ID` → terhubung ke backend sungguhan.
- Lihat `PANDUAN-INSTALASI.md`.
